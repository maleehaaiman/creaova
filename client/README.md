# Creova Client

This directory contains the React and Vite frontend for Creova, a creator and brand collaboration marketplace.

## Commands

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

The frontend communicates with the backend through the `/api` path. During local development, Vite proxies API requests to the Express server configured in `vite.config.js`.

See the repository root [README](../README.md) for complete project setup, environment variables, features, API areas, and database requirements.
